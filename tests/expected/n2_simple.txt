=== n2_simple.t77 ロード手順 (FM-7 F-BASIC) ===

  エントリアドレス     : $3000
  実データ             : 20224 bytes (19.8 KiB)
  16 KiB チャンク数    : 2
  末尾ゼロパディング   : 12544 bytes

  最終メモリ配置:
    チャンク#0  -> $3000-$6FFF
    チャンク#1  -> $7000-$AFFF

  (PC 側で D77 -> T77/WAV/TXT を変換する手順は README.TXT を参照)

──────────────────────────────────────────────────
 操作手順 (F-BASIC OK プロンプトで以下を順に入力)
──────────────────────────────────────────────────

  CLEAR ,&H13FF

  [1/2] C01  チャンク#1 (rev_int)
        LOADM "CAS:"
        EXEC &H1400
        ; stager がチャンクを最終位置 $7000-$AFFF へ配置

  [2/2] C02  チャンク#0 (rev_last, 最終)
        LOADM "CAS:",,R
        ; auto-exec で stager が動作:
        ;   バッファ -> $3000 (rev copy)
        ;   LDS #$FBFF / JMP $3000

──────────────────────────────────────────────────
 補足
──────────────────────────────────────────────────

  - CLEAR ,&H13FF で MEMSIZ を $13FF に下げ、
    $1400-$7FFF をユーザ作業域として確保する

  - 各 LOADM ブロックは単一連続 ($1400-$5FFF) で構成:
      $1400-$1419  Stage 1                      (26 B)
      $141A-$143x  Stage 2 source (19/23/39 B)
      $142D-$1432  復帰ルーチン (中間パスのみ、6 B)
      $143x-$1FFF  ゼロパディング
      $2000-$5FFF  16 KiB バッファ

  - Stage 1 は IRQ マスク + ROM OFF + Stage 2 を $D000 (URA RAM)
    へコピーして JMP $D000。Stage 2 は最終コピー(/ relocate) を
    実行し、中間パスなら $142D の復帰ルーチンへ JMP (そこで ROM ON
    + RTS)、最終パスなら LDS + JMP entry

  - EXEC は必ず明示的にアドレスを指定すること
    (引数なし EXEC は実機で挙動が不安定)
