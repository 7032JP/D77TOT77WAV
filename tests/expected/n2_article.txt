=== n2_article.t77 ロード手順 (FM-7 F-BASIC) ===

  エントリアドレス     : $0200
  実データ             : 20224 bytes (19.8 KiB)
  16 KiB チャンク数    : 2
  末尾ゼロパディング   : 12544 bytes

  最終メモリ配置:
    チャンク#0  -> $0200-$41FF
    チャンク#1  -> $4200-$81FF

  (PC 側で D77 -> T77/WAV/TXT を変換する手順は README.TXT を参照)

──────────────────────────────────────────────────
 操作手順 (F-BASIC OK プロンプトで以下を入力)
──────────────────────────────────────────────────

  テープの先頭に BASIC ローダ (LOADER, アスキー形式) が
  入っている。次の 1 行だけで起動する:

        RUN "CAS0:"

  ローダの中身 (CLEAR と各パスの LOADM をプログラムが順に実行する):

        10 CLEAR ,&H13FF
        20 LOADM "CAS0:",,R
        30 LOADM "CAS0:",,R

──────────────────────────────────────────────────
 テープ構成 (LOADER の後に続く機械語ファイル)
──────────────────────────────────────────────────

  [1/2] C01  チャンク#0 (rev_int (stash))  <- ローダ 20 行目
        ; auto-exec で stager がチャンクを URA RAM ($8200-$C1FF) へ退避
        ;   ROM ON + RTS でローダの次の行へ戻る

  [2/2] C02  チャンク#1 (relocate2, 最終)  <- ローダ 30 行目
        ; auto-exec で relocator が動作:
        ;   M1 reverse  $2000-$5FFF -> $4200-$81FF
        ;   M2 forward  $8200-$C1FF -> $0200-$41FF
        ;   LDS #$FBFF / JMP $0200

──────────────────────────────────────────────────
 補足
──────────────────────────────────────────────────

  - CLEAR ,&H13FF で MEMSIZ を $13FF に下げ、
    $1400-$7FFF をユーザ作業域として確保する

  - 各 LOADM ブロックは単一連続 ($1400-$5FFF) で構成:
      $1400-$1419  Stage 1                      (26 B)
      $141A-$143x  Stage 2 source (19/23/39 B)
      $142D-$1432  復帰ルーチン (中間パスのみ、6 B)
      $143x-$1FFF  ゼロパディング
      $2000-$5FFF  16 KiB バッファ

  - Stage 1 は IRQ マスク + ROM OFF + Stage 2 を $D000 (URA RAM)
    へコピーして JMP $D000。Stage 2 は最終コピー(/ relocate) を
    実行し、中間パスなら $142D の復帰ルーチンへ JMP (そこで ROM ON
    + RTS)、最終パスなら LDS + JMP entry

  - 全パスを LOADM "CAS0:",,R で起動する。中間パスは RTS で
    BASIC へ戻るのでローダの次の行へ続き、最終パスは JMP entry で
    戻らない

  - LOADER は SAVE "CAS0:",A と同じアスキー形式で記録した
    BASIC プログラム。RUN "CAS0:" がヘッダの属性から形式を判別して
    読み込み、そのまま実行する
