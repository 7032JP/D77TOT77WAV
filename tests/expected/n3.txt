=== n3.t77 ロード手順 (FM-7 F-BASIC) ===

  エントリアドレス     : $2000
  実データ             : 36608 bytes (35.8 KiB)
  16 KiB チャンク数    : 3
  末尾ゼロパディング   : 12544 bytes

  最終メモリ配置:
    チャンク#0  -> $2000-$5FFF
    チャンク#1  -> $6000-$9FFF
    チャンク#2  -> $A000-$DFFF

  (PC 側で D77 -> T77/WAV/TXT を変換する手順は README.TXT を参照)

──────────────────────────────────────────────────
 操作手順 (F-BASIC OK プロンプトで以下を順に入力)
──────────────────────────────────────────────────

  CLEAR ,&H13FF

  [1/3] C01  チャンク#2 (rev_int)
        LOADM "CAS:"
        EXEC &H1400
        ; stager がチャンクを最終位置 $A000-$DFFF へ配置

  [2/3] C02  チャンク#1 (rev_int)
        LOADM "CAS:"
        EXEC &H1400
        ; stager がチャンクを最終位置 $6000-$9FFF へ配置

  [3/3] C03  チャンク#0 (fwd_last, 最終)
        LOADM "CAS:",,R
        ; auto-exec で stager が動作:
        ;   バッファ -> $2000 (fwd copy)
        ;   LDS #$FBFF / JMP $2000

──────────────────────────────────────────────────
 補足
──────────────────────────────────────────────────

  - CLEAR ,&H13FF で MEMSIZ を $13FF に下げ、
    $1400-$7FFF をユーザ作業域として確保する

  - 各 LOADM ブロックは単一連続 ($1400-$5FFF) で構成:
      $1400-$1419  Stage 1                      (26 B)
      $141A-$143x  Stage 2 source (22/23/39 B)
      $143x-$1FFF  ゼロパディング
      $2000-$5FFF  16 KiB バッファ

  - Stage 1 は IRQ マスク + ROM OFF + Stage 2 を $D000 (URA RAM)
    へコピーして JMP $D000。Stage 2 は最終コピー(/ relocate) を
    実行し、中間パスなら ROM ON + RTS、最終パスなら LDS + JMP entry

  - EXEC は必ず明示的にアドレスを指定すること
    (引数なし EXEC は実機で挙動が不安定)
